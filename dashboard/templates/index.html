Consistency & error handling
Preprocessing is part of the model.
Inference calls the exported preprocessing code and checks its SHA-256 hash, parameter fingerprint, and each model's input settings. Mismatches prevent model readiness.
Errors have a predictable contract.
{ "error": { "code": "…", "message": "…" }, "request_id": "…" }
Invalid audio, unsupported inputs, and unavailable models produce a clear message in the workspace.
Machine identification source
Machine type comes from your selection or a labeled filename. The anomaly detector does not identify machine type acoustically.
